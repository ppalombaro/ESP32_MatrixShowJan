Timeline JSON

Firmware font is 5×7, ASCII 32–90, text is upper-cased on load. Colour cycles theme colour 1 → 2 → 3 each full pass. The two windows are treated as one 40-wide strip.

Left window = Days / Hours, right window = Minutes / Seconds (firmware DIGIT_3×5). targetDate is local wall-clock "YYYY-MM-DD HH:MM:SS" (DST-aware on device) or an epoch integer. Header uses theme colour 1, digits colour 3.

Schemas the firmware actually reads

SCENE      { "centerX":10, "centerY":12, "durationMs":5000,
             "matrix0Scene":"<path>", "matrix1Scene":"<path>",
             "pixels":[ {"x":0,"y":-5,"r":255,"g":128,"b":0}, ... ] }
           x/y are offsets from centerX/centerY. Usable abs 0..19 (x), 0..24 (y).
           matrix0Scene -> RIGHT window, matrix1Scene -> LEFT window (default: self / mirror).

TIMELINE   { "loop":true, "durationMs":0, "theme":"halloween",
             "frames":[
               {"scene":"eyes_center","durationMs":500},
               {"matrix1Scene":"letter_O","matrix0Scene":"letter_H","durationMs":1000}
             ] }
           durationMs 0/absent -> sum of frame durations (frame default 100). loop:false holds last frame.
           bare "scene" names resolve to <timeline folder>/<name>.json; a value with "/" is used as-is.
           ""/"blank" (empty pixels) = dark panel.

SCROLL     { "text":"GO BUCKS", "speed":50 }        upper-cased, font ASCII 32-90
COUNTDOWN  { "targetDate":"2026-11-28 12:00:00", "comment":"...", "durationMs":5000 }
TEST       any json; renderer ignores it and fills both windows solid red
